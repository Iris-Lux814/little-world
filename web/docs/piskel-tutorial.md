# 用 Piskel 画自己的小人

Piskel 是免费的像素画工具，网页版打开就能用：<https://www.piskelapp.com/>（也有离线版）。下面从自带的通用小人改一张。

## 1. 把通用小人导进来

1. 下载 `public/sprites/starter.png`（240 × 320，就是格子说明图里那个光头小人）。
2. 打开 Piskel，点 **Create Sprite**。
3. 右边栏点 **Import**（导入）→ 选 `starter.png`。
4. 选 **Import as spritesheet**（按格子切成帧），帧宽 **48**、帧高 **64**，偏移都是 0，确定。

左边会出现 25 帧，顺序是一行一行从左到右：

| 帧 | 内容 |
|---|---|
| 1～5 | 朝下：站、走1、走2、走3、走4 |
| 6～10 | 朝左：同上 |
| 11～15 | 朝右：同上 |
| 16～20 | 朝上：同上 |
| 21～25 | 甩竿1、甩竿2、甩竿3、坐、空 |

第 25 帧是空的，**别删**——少一帧导出来的图就不是 240 × 320 了。

## 2. 改

- 最省事的是在光头小人身上加东西：头发、衣服、帽子、配饰。新建一个图层画在上面，原来的身体不用动，动作就都对。
- 每一帧都要改到。可以打开 **Onion skin**（洋葱皮，半透明显示前后帧）对着画，保证每帧的头发、衣服在同一个位置。
- **脚底别动**：脚踩在每格第 60 行（从上往下数），游戏按这条线对齐人站在哪。
- **头别晃**：走路时头的位置基本不变，只有身体和腿在动；不然走起来像在扭脖子。
- **走路要换腿**：走1 和 走3 是左右腿互换的，画完把这两帧来回切着看一下。
- **侧面远处那条腿 / 胳膊画暗一点**，不然左右分不清。
- 朝左那一行可以复制朝右那一行再 **水平翻转**（Piskel 的变换工具里有 Flip）。翻的时候注意整格一起翻，脚还要在原来的位置。
- 甩竿三帧是朝右画的，朝左时游戏会自己镜像；鱼竿不用画。
- 「坐」那一帧是正面坐着：屁股大概在第 50 行左右，腿收短。

右上角的小窗口会播放动画，可以随时看效果。

## 3. 导出

右边栏点 **Export** → **PNG**：

- 导出成一整张 spritesheet，**列数（columns）填 5**（5 × 5 正好 25 帧）
- 缩放保持 **1 倍**
- 下载

检查一下下载的图：**240 × 320、透明底**。不对的话多半是帧数不是 25，或者缩放不是 1 倍。

## 4. 传进游戏

```bash
curl -X POST --data-binary @my-sprite.png -H "Content-Type: image/png" http://127.0.0.1:29901/api/world/sprite
```

- 给伙伴换：地址后面加 `?who=buddy`（伙伴的 id 看 `GET /api/world` 里的 `roles`）
- 换回默认：`curl -X DELETE http://127.0.0.1:29901/api/world/sprite`

传完回到游戏，几秒内画面上的人就换了。尺寸不对、超过 512KB 或不是 PNG 的话，接口会直接告诉你哪里不对。
